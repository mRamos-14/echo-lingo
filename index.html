⬇ Download for Windows echo-lingo-windows.exe

Install on Windows

  1. Download echo-lingo-windows.exe and double-click it. It runs straight away, nothing to set up.
  2. Windows may say “Windows protected your PC” because the app isn't signed by a paid certificate: click More info → Run anyway.
  3. Pin it to your taskbar or move the file wherever you like. Lessons and audio are inside, so it works offline.
⬇ Download for Android echo-lingo.apk

Install on Android

  1. Tap Download for Android above.
  2. Open the downloaded echo-lingo.apk (from the notification or your Downloads).
  3. If your phone asks, allow your browser to install unknown apps, then go back.
  4. Tap Install, then Open. Echo Lingo is now a normal app in your app drawer.

It's a standalone app: lessons and all audio are inside it, so it works without internet. When a new version is out, the app shows a Download update button, and installing it keeps your progress.

No download? Install from Chrome

  1. Open this link in Chrome (not Brave or another browser).
  2. Tap ⋮ → Install app. Don't use “Add to home screen” or “Create shortcut”: those make a badged browser shortcut.
  3. Chrome turns it into a real app: no browser badge, listed in your app drawer and Settings → Apps. Updates arrive through the in-app Update now button.

iPhone

Apple doesn't allow installing app files from the internet. On iPhone, Echo Lingo installs from Safari instead:

  1. Open this link in Safari (not Chrome).
  2. Tap the Share button, then Add to Home Screen, then Add.
  3. Open Echo Lingo from your home screen. Tap Save audio for offline once, and it works without internet.
